# HexSoftwares_EDA-on-a-Public-Dataset
Exploratory Data Analysis using Jupyter Notebook.

🛳️ Titanic Dataset – Exploratory Data Analysis (EDA)

A comprehensive data exploration project using Python, Pandas, Matplotlib, and Seaborn.

📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on the Titanic Dataset, a widely-used public dataset for learning data analysis and pattern discovery.

The goal of this analysis is to:
Understand the structure and quality of the dataset
Explore relationships between features
Identify patterns affecting passenger survival
Perform descriptive statistics, visualizations, and correlation analysis

The notebook used for this analysis is:
HexSoftwares_EDA_on_public_dataset.ipynb

📂 Dataset Information
Dataset: Titanic-Dataset.csv
The dataset contains information about Titanic passengers, including:
Demographic details (Age, Sex, Class)
Travel details (Fare, Cabin, Embarked)
Survival information

This dataset is ideal for practicing:
Cleaning
Transformation
Visualization
Statistical insights

🧪 Technologies & Libraries Used
Library	Purpose

Matplotlib -	Data visualization

Jupyter Notebook- Interactive development environment

🔍 Key Analysis Performed
✔ 1. Data Loading & Inspection
Loaded the CSV dataset
Checked rows, columns, and data types
Identified missing values

✔ 2. Data Cleaning
Handled null values
Converted data types where needed
Removed duplicates

✔ 3. Univariate Analysis
Distribution of Age
Count plot of Gender
Count plot of Survival
Ticket class distribution

✔ 4. Bivariate / Multivariate Analysis
Survival rate by gender
Survival rate by passenger class
Age vs. Survival
Fare comparison across classes

✔ 5. Correlation Analysis
Heatmap of correlated features
Pair-wise relationships

These visualizations help identify:
Trends in survivability
